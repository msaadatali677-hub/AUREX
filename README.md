# AUREX — Men's Luxury Perfume Store

**AUREX — Scent of Confidence** is a modern men's luxury perfume storefront designed with an elegant dark theme and Glassmorphism UI. It showcases premium fragrances through a stylish, responsive, and interactive shopping experience.

🌐 **Live Demo:** [https://aurex-perfume.vercel.app/](https://aurex-perfume.vercel.app/)

💻 **GitHub Repository:** [https://github.com/msaadatali677-hub/AUREX](https://github.com/msaadatali677-hub/AUREX)

---

## ✨ Features

- **Modern Glassmorphism Design** — Elegant dark luxury interface with gold accents.
- **Responsive Layout** — Optimized for desktop, tablet, and mobile devices.
- **Product Showcase** — Display of men's luxury perfume products.
- **Product Search** — Search perfumes by name.
- **Product Filtering** — Explore products by category and collection.
- **Product Sorting** — Sort products using available sorting options.
- **Quick View** — View perfume details, prices, ratings, and fragrance notes.
- **Shopping Cart** — Add and manage products in the cart.
- **Wishlist** — Save and manage favorite perfumes.
- **Newsletter UI** — Frontend email validation with demo feedback.
- **Mobile Navigation** — Responsive navigation menu.
- **Interactive UI** — Smooth transitions, animations, and user-friendly controls.

## 🚀 Getting Started

Follow these steps to run the project locally.

**1. Clone the repository**

```bash
git clone https://github.com/msaadatali677-hub/AUREX.git
```

**2. Open the project folder**

```bash
cd AUREX
```

**3. Run the website**

Open `index.html` in your browser, or use the **Live Server** extension in Visual Studio Code.

## ⚠️ Demo Notice

AUREX is a frontend demonstration project.

- No real payment processing is integrated.
- Checkout is for demonstration purposes only.
- Account functionality is not connected to a backend.
- Newsletter submissions are not stored or sent to a server.
